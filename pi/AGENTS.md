# Global Pi working agreement

- Read and follow the nearest project `AGENTS.md` or `CLAUDE.md` before acting.
- Inspect first. Preserve unrelated work and never discard user changes.
- Ask before destructive actions, production changes, credential access, or external writes.
- For non-trivial work, make the goal and verification criteria explicit, then finish and verify the task.
- Prefer repository-native commands and focused context over broad scans.
- End with the outcome, changed files, checks run, and any remaining risk.
