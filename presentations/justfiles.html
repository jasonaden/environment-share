01 // What is just?

A Command Runner
Without the Baggage

Like make but no build system opinions. One file, any stack, cross-platform.

  • Self-documenting — comments become help text
  • Variables, arguments, aliases, dependencies
  • Walks up the directory tree — works from anywhere
$ brew install just Install
$ just --list See all recipes
$ just deploy staging Run a recipe
Syntax

02 // Syntax Tour

Anatomy of a Justfile

# Comment becomes the description in --list
deploy env="staging":
    ./scripts/deploy.sh {{env}}

# Aliases provide shorthand
alias d := deploy

# Recipes can depend on other recipes
release: test lint build
    just deploy production

# Multi-line shell blocks
setup:
    #!/usr/bin/env bash
    set -euo pipefail
    npm install && npm run db:migrate
