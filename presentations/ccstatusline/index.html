04 // Tokens

Input / Output / Cached

... | 15.2k/3.4k/12k | ...

Input — 15.2k

Everything sent to Claude this turn: your messages, file contents, tool results, system prompt. The entire conversation re-sent each turn.

Output — 3.4k

Everything Claude writes back: responses, code, tool calls. Most expensive per-token — typically 5x the cost of input.

Cached — 12k

Input tokens reused from a previous turn. 90% cheaper than regular input. The higher this number relative to input, the better.

05 // Pricing

What tokens
actually cost

Tokens are the billing unit. ~4 characters = 1 token. Output is always the most expensive. Cached input is the cheapest.

Watch your status line: as a conversation continues, the cached count grows closer to input. That's the caching working in your favor.

Model Input Output Cached
Opus 4.6 $5/M $25/M $0.50/M
Sonnet 4.6 $3/M $15/M $0.30/M
Haiku 4.5 $1/M $5/M $0.10/M

$/M = dollars per million tokens. Output is 5x input. Cached reads are 10x cheaper than input.

07 // Git Worktree

Isolated
workspaces

... | 𖠰 main | ...

A separate working copy of the same repo. One repo, multiple checkouts, different branches simultaneously.

When you'll see this

Claude Code spawns agent teammates in isolated worktrees so they edit files without conflicting with your main workspace.

Branch vs. Worktree

Branch = which version of history.
Worktree = which physical directory. Multiple worktrees can be on different branches simultaneously.

⎇feature/auth | 𖠰 auth-work

Branch "feature/auth" in worktree "auth-work"

09 // Install

Get this status line

Barebones

Default install

Adds ccstatusline to Claude Code with default segments. Configure it yourself via the interactive TUI.

1 claude config set statusLine '{"type":"command","command":"npx -y ccstatusline@latest","padding":0}'
2 npx ccstatusline@latest configure
Pre-configured

Install with this layout

Clones the config repo, copies settings, and hooks ccstatusline into Claude Code. Ready to go.

1 git clone <repo> ~/environment-share
2 ~/environment-share/ccstatusline/install.sh
3 claude restart
